# One-project Luna trial

Free accounts can try the built-in Luna agent on one project without a payment card. The lifetime allowance is $0.50 of conservative model cost, shared by the initial draft, clarifications and separate To-be revisions. It does not renew monthly. Pro continues to include $6 per billing period at $29/month.

The first submitted message claims the trial. Before creation, the claim belongs to that conversation; after creation it belongs to the saved project. Another conversation on that project uses the same allowance. Another project, an upgrade followed by cancellation, or a new calendar day cannot reset it. Accounts at their project limit must choose an existing project before claiming a trial.

Reservations enforce the allowance before every provider call. Failed or unmeasurable calls retain their operational cost in the trial ledger. Payment review holds also block trial calls. Existing operator, paid-account and service spending limits remain in force. When the allowance cannot fund another turn, saved conversations, sources, evidence, revisions and downloads remain available. A connected personal agent can still edit the project. Trial use never starts a paid subscription.

## Validation

The local Cloudflare Worker, actual chat UI and live Luna provider completed six ordinary business-analysis turns for a previously unseen bike-rental process:

1. Create a project from an interview alone and save a first overview.
2. Clarify missing information, availability, quote deadlines, reminders and closure outcomes.
3. Clarify late acceptance and declined quotes.
4. Create a separate future model with automatic quote and confirmation emails.
5. Revise the future model with automatic missing-information emails and wrong-address correction and retry.
6. Automate the one-time reminder while preserving the original wait and deadline.

All six runs completed once. Their conservative cost total was $0.182218625, leaving $0.317781375. This is one measured example, not a promise of a fixed number of messages or projects.

Independent checks read all ten immutable saved snapshots, rather than trusting the assistant's replies. They verified source hashes, exact evidence excerpts, references, draft status without human approval, revision parent chains, separate model histories, the fixed As-is revision 4 planning baseline and the unchanged current model through later future-model edits. Graph checks verified the untimed missing-information wait, availability and acceptance outcomes, two-day noninterrupting reminder, five-day closure, successful delivery before the quote clock, and wrong-address retry. The future model has exactly the four requested automatic activities; the current model has none.

Actual browser downloads of As-is revision 4 and To-be revisions 2 and 6 parsed without warnings and matched the respective saved BPMN semantics. Reloads, model and revision navigation, readable mobile evidence, the trial notice, a second-project denial and a new conversation preserving the allowance were checked in the UI.

Exhaustion was simulated only in the owned local test account, after preserving the six real runs. Further Luna input stopped while saved chat and diagram downloads remained available. Only the synthetic accounting row was removed afterward; all real usage was retained. No production billing meter was modified for this test.

Regression tests cover racing first claims, lifetime accounting, failed and unknown costs, per-call enforcement, selected-project isolation, a payment hold appearing between calls, paid upgrade and lapse, and a full workspace retaining its unclaimed trial. The existing Cloudflare SDK and browser regression journeys also pass.

Private artifacts are under `tmp/free-trial-qa/`. They contain fictional test sources and local account records and are intentionally excluded from publication. Production rollout is verified separately against the deployed commit and migration receipt.
